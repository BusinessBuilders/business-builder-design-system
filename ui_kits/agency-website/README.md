# Agency Website — UI Kit

3-tier pricing page for the Business Builder web-development & AI-automation agency.

## Files
- `index.html` — full pricing page (header, hero, 3-tier pricing grid, FAQ, footer)
- `Header.jsx` — top nav with logo + plain links + CTA
- `Hero.jsx` — eyebrow + script display headline + subhead + CTAs
- `PricingGrid.jsx` — 3 tiers with feature lists, featured middle card with sticker
- `FAQ.jsx` — collapsible "questions you'll ask" block
- `Footer.jsx` — 3-column footer with cream-on-black

## Notes
- Built directly on `colors_and_type.css` tokens — no new colors invented.
- Featured tier (middle) uses orange ring + brick stacked drop shadow + script "most popular!" sticker rotated -6°.
- Icons via Lucide CDN, monoline at 1.75 stroke. See `ICONOGRAPHY` in root README.
